# Evaluation Rubric

Score each category from 0 to 5. A promotion recommendation requires no hard-boundary failure and at least 32/40 overall.

## 1. Experience coherence

- 0: disconnected sections
- 3: understandable path with weak transitions
- 5: arrival, transmission, puzzle, revelation, and gateways feel like one experience

## 2. Atmosphere

- 0: generic template
- 3: some cinematic qualities
- 5: distinctive sacred-technical identity without cyberpunk cliché

## 3. Interaction quality

- 0: broken or confusing
- 3: solvable but rough
- 5: intuitive, responsive, satisfying, and clearly linked to the story

## 4. Mobile usability

- 0: unusable on phone
- 3: functional with layout problems
- 5: polished at 360px and comfortable on Android touch screens

## 5. Accessibility

- 0: inaccessible
- 3: partial keyboard and contrast support
- 5: semantic, keyboard-friendly, visible focus, reduced motion, audio optional

## 6. Zero-cost resilience

- 0: requires paid or remote services
- 3: mostly static with avoidable dependencies
- 5: fully static, self-contained, and deployable free

## 7. Canon discipline

- 0: invents or exposes forbidden canon
- 3: mostly bounded with ambiguous leakage
- 5: uses Kael, preserves mystery, labels mock material, never self-promotes

## 8. Technical quality

- 0: errors or fragile build
- 3: works with minor issues
- 5: clean structure, no console errors, documented run path, tested success and reset states

## Hard failures

Any one of these blocks promotion regardless of score:

- Juno used as the current protagonist
- claim of canonical approval
- paid dependency or live AI requirement
- secret, token, or `.env` committed
- edit under `canon/`
- dependency on another repository
- no human promotion packet
- puzzle cannot be completed with touch or keyboard
- autoplay audio or unsafe flashing

# Codex Handoff Template v0.1

## Required context

- AGENTS.md context
- Mission Control snapshot
- Continuity packet
- Repo target
- Current branch and base commit
- Allowed files
- Forbidden files
- Tests to run
- Expected output
- Rollback expectation
- Mission Control write-back summary

## Rule

Codex receives bounded jobs only. No broad refactor, no private state, no secrets, no `git add .`.

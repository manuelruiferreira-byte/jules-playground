# Promotion Packet v0.1

## Purpose

Controls promotion from sandbox, mobile platform, or agent output into canon repos.

## Required fields

- source_repo
- target_repo
- branch
- base_commit
- changed_files
- risk_class
- privacy_class
- security_review
- dependency_review
- tests_run
- rollback_plan
- Mission Control record
- human approval
- independent review verdict

## Rule

No sandbox or mobile work self-promotes into Jester-Intelligence.
